## 작업 개요
1024px 이하에서 사이드바를 연 상태면 사이트 상세의 게시글 목록 표가 `<main>`을 12~38px 넓혀 페이지 전체에 가로 스크롤이 생깁니다(2026-09-21 Chromium 측정).

## 원인
- `app/_components/LayoutWrapper.tsx`의 `<main>`이 `flex-1`만 있고 `min-w-0`이 없어, 표의 최소 폭만큼 `<main>`이 늘어남
- `min-w-0`만 추가하면 `app/sites/page.tsx`의 사이트 목록 표가 `overflow-hidden` 카드 안에 있어 넓은 표가 잘림

## 작업 범위

### 포함
- `<main>`에 `min-w-0` 추가 + `app/sites/page.tsx` 표 wrapper를 `overflow-x-auto`로 변경 (두 줄을 함께 적용)
- 768/1024/1280px, 사이드바 열림·닫힘에서 확인

### 제외
- 모바일 전용 레이아웃 재설계
