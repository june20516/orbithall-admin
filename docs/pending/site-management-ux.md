## 지금 어드민에서 가능한가
**가능.** 필요한 데이터는 기존 API로 받을 수 있습니다.
- `GET /admin/sites`: 검색·정렬·페이지 파라미터가 없고 전체 목록을 반환 → 정렬·검색은 클라이언트에서 처리
- `GET /admin/sites/{id}`: `api_key` 포함 → 상세 페이지 표시 가능

## 작업 개요
`docs/completed/site-crud-feature.md`의 "사용자 경험 개선", "향후 개선사항" 중 아직 하지 않은 항목입니다.

## 작업 범위

### 포함
- 생성·수정·삭제 성공/실패 토스트 메시지
- 사이트 목록 정렬(이름, 생성일, 상태)과 이름·도메인 검색
- 사이트 상세 페이지에 API Key 표시와 복사 (지금은 수정 페이지에만 있음)

### 제외
- 서버 측 검색·정렬·페이지네이션 (사이트 수가 많아지면 백엔드 과제로 분리)
- API Key 재발급 (별도 과제: `api-key-regeneration.md`)
