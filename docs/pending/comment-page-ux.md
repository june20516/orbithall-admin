## 작업 개요
2026-09-21에 배포한 `/sites/[id]/posts/[slug]` 페이지의 리뷰·수동 확인에서 나온 개선 항목입니다.

## 작업 범위

### 포함
- **범위를 넘는 페이지:** `?page=999`에서 "최상위 댓글 55개", "댓글이 없습니다", "999 / 2 페이지"가 함께 보임 → 안내 문구를 바꾸거나 마지막 페이지로 보정
- **페이지 이동 로딩 표시:** `?page=N` 이동 시 이전 목록이 그대로 있다가 바뀜 → `DataBoundary`에 `key={page}` 등으로 로딩 표시
- **삭제 댓글 대비:** `opacity-60` 때문에 본문 대비가 WCAG AA(4.5:1) 미달 → 배경 톤이나 테두리로 삭제 상태를 표시하는 방식 검토 (디자인 결정 필요)
- **제목·Slug 중복 (불편하면):** 게시글 목록에서 위젯이 slug를 title로 저장하는 설계라 두 칸이 같은 값으로 보임 → 필요해지면 title == slug일 때 Slug 칸 처리
