## 작업 개요
API Key가 유출되었을 때 사이트 수정 페이지에서 새 키로 교체할 수 있게 합니다.

## 작업 범위

### 포함
- 사이트 수정 페이지의 API Key 영역에 "재발급" 버튼과 경고 다이얼로그 (이전 키는 즉시 사용 불가, 위젯 설정 교체 필요)
- 재발급 후 새 키 표시·복사

### 제외
- 이전 키 유예 기간
